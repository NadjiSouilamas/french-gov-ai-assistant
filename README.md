# 🇫🇷 AI Assistant for French Government Services

## Overview
This project builds a **Retrieval-Augmented Generation (RAG)** assistant that answers citizen questions using information from [Service-Public.fr](https://www.service-public.fr/).

Example queries:
- "Comment renouveler mon passeport ?"
- "Quelles sont les aides au logement disponibles ?"

The goal is to make a **useful, multilingual AI system** while demonstrating:
- Document ingestion and chunking
- Vector embedding & retrieval
- LLM-powered contextual answering
- API serving with FastAPI
- Deployment with Docker/AWS
